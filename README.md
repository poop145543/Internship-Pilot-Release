# Internship Pilot — Windows Releases

This public repository hosts downloadable **compiled Windows installer releases** for Internship Pilot.

The application source code is kept in a separate private repository.

## Downloading

Use the [Releases page](https://github.com/poop145543/Internship-Pilot-Release/releases) to download a Windows setup installer when a release is published.

## Important

- This repository must contain **no personal data**, résumés, saved passwords, Gmail tokens, OAuth credentials, or encrypted application vaults.
- Official release assets are produced by the private source repository's GitHub Actions publishing workflow.
- App updates require the published installer, `latest.yml`, and matching release metadata.
- Windows installers may be unsigned during early testing. Verify the publisher and release before installing.
